The problem

GPUs get the budget. DRAM gets the silence.

Inference fleets are provisioned for peak KV-cache and then sit mostly cold. Nobody’s watching, because the tooling that already exists in the kernel isn’t wired up.

01

DRAM is now the second-biggest line item on most inference fleets, right after the accelerators — and it’s the one nobody instruments.

02

Fleets are sized for the worst hour of the day. Outside of that hour, a large share of allocated memory just sits there, untouched, fully paid for.

03

The kernel already knows what’s cold. DAMON, PSI, and cgroup v2 expose access patterns today — almost nobody scrapes them into a decision.

Collectors

One agent, every signal that actually matters.

memauditd runs as a single lightweight daemon and pulls from the sources that already exist on your boxes — no kernel patches, no sidecars per GPU.

meminfokernel

Baseline memory accounting — free, cached, buffers, swap — sampled continuously.

PSIkernel

Pressure stall information: how long processes actually wait on memory, not just how much they hold.

NUMAkernel

Per-node allocation and access locality, so tiering decisions respect topology instead of fighting it.

cgroup v2kernel

Per-workload memory accounting that maps straight onto how you already isolate tenants.

DAMONkernel

The kernel’s own access-pattern monitor, read straight from sysfs — the source of the hot/cold classification.

NVMLgpu

GPU memory and utilization, correlated against host-side pressure to catch host/device imbalance.

vLLMgpu

Scrapes vLLM’s own Prometheus endpoint to tie KV-cache size directly to the pages backing it.

Pipeline

From /proc to a decision.

Every collector lands in the same pipeline, so a page’s temperature is always traceable back to the raw signal that produced it.

01 collect
Agent samples kernel + GPU sources on every host.
02 ingest
Samples batched and shipped off-host, gaps and clock skew handled.
03 store
Written to ClickHouse as a time series, one row per page range per interval.
04 analyze
Query set classifies hot / warm / cold and flags tiering candidates.
05 report
A plain summary of what’s cold, where it lives, and what it’s costing you.
